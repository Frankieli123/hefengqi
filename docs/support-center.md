# 技术支持中心：第一期页面框架

## 已接入

- 三语入口：`/[locale]/support/troubleshooting`；`/[locale]/support` 重定向到入口。
- 型号页面：`/[locale]/support/troubleshooting/[brand]/[model]`，品牌与型号经过 URL 编码，使用不随翻译变化的原始字段。
- PC、移动导航、页脚与聚合页站点地图。
- 型号搜索、品牌与设备类型筛选、分页、无结果状态。筛选保存在 URL 中。
- 使用当前公开产品库，产品下架或语言未发布时不会生成对应支持页。
- 指南区读取后台已发布的“教程指南”和“选购指南”。设备页的相关文章只使用后台明确配置的产品关联。
- 设备页可将型号、软件版本和告警原文预填入现有咨询表单，用户确认后才提交。

## 内容与索引边界

当前是可使用的页面框架，并非已经录入完整告警库。没有录入虚构的故障代码、指示灯状态、测量阈值或备件兼容关系。

型号页展示资料缺失状态，并设置 `noindex, follow`，不进入 sitemap。聚合页可索引，查询及分页组合不索引。结构化数据仅描述实际页面，不生成默认 HowTo 步骤。

现有产品、品牌、分类、技术文章仍在原后台维护；本期未新增数据库表、专用告警编辑器、导入接口或公开 PDF 下载功能。

## 组件与设计

- `src/components/support/`：聚合页、型号页、轻量筛选组件及独立样式。
- `src/content/support.ts`：中文、英文和俄文文案。
- `src/lib/support-repository.ts`：现有公开资料的服务端适配层。
- `src/lib/support.ts`：路由、搜索与分类规则。

页面遵循 `docs/design-system.md`：同款黑色栏目标题区、白底搜索、8px 圆角、细线列表、红底咨询 CTA。移动端筛选与目录可折叠，分页保持紧凑。所有产品数据留在服务端，只渲染当前页结果。

## 下一期内容接入

拿到含来源和适用版本的资料后，再增加独立手册、告警、步骤及翻译模型、后台复核与导入 API。数据量扩大时，将适配层改为数据库条件查询和分页。

版本核验后的告警和步骤替换当前缺失状态；备件按准确型号和兼容条件关联。仅资料完整的型号手册开放索引，发布时同步刷新站点和 EdgeOne 缓存。
