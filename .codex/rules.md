# 科技企业官网开发规范


## 项目定位

这是一个科技企业品牌官网。

不是：
- 后台系统
- SaaS Dashboard
- 电商页面


## 设计方向

参考：

Huawei Enterprise
NVIDIA
Apple
Tesla


风格：

- 科技
- 简洁
- 高端
- 国际化
- 大留白


禁止：

- 大量卡片堆叠
- 紫色AI渐变
- 普通Bootstrap风格
- 廉价企业模板


## 技术栈

Next.js
TypeScript
Tailwind CSS


动画：

GSAP
Framer Motion


## 开发要求

写代码前：

1. 分析页面结构
2. 输出设计方案
3. 规划组件


代码：

- 组件拆分
- 可维护
- SEO友好
- 移动端适配


## 页面结构

首页：

Hero
企业介绍
产品展示
解决方案
行业应用
案例

# SEO GEO Rules


## 网站定位

科技企业官网


## SEO要求

每个页面必须：

- 独立Title
- Meta Description
- H1唯一
- Schema结构化数据
- OpenGraph


## GEO要求

内容必须方便AI理解：

每个产品页面包含：

1. 产品是什么
2. 解决什么问题
3. 适合谁
4. 核心优势
5. 技术参数


## 企业实体

统一：

公司名称
品牌名称
产品名称
